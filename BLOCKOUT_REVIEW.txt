ASUN IMG DESKTOP 1.6.7 — INDEPENDENT BLOCKOUT REVIEW
Implemented 2026-10-26 for Desktop Generate. Complete reference packs gained portable receiving-agent instructions on 2026-10-27. Character/item-sheet generation remains separate from the fixed-camera review.

USE
Save your work and refresh the desktop editor (Ctrl+R). Beside Generate, choose Blockout review. Select the original Blender blockout explicitly, confirm the preview, optionally list allowed structural changes, and save. Generate normally. The review setting is project-local and starts off until an original is selected; existing ordinary generation behavior and the default image quality stay unchanged.

Reviewer: gpt-6-astra, reasoning.effort=max. Ultra is a Codex host setting, not a supported public Responses API effort. The app does not substitute another reviewer. API model access was verified on this PC; no paid image generation or live vision review was performed for implementation testing.

Each candidate is independently checked for framing, camera perspective, placement, projected scale, orientation, occlusion, content and reference appearance. An explicit rejection supplies corrections to the next generation using the same original inputs and image model/quality. Maximum: 3 total image attempts (configurable 1–3), each with a review. Calls use paid API billing. Only all eight passing checks yield Visual match passed. Inconclusive, failed or exhausted reviews stop with Needs review; the latest candidate can be inspected, saved or edited from Job queue / Generation history.

SOURCE AND CAMERA
The chosen original bytes/hash remain fixed across attempts, independently of canvas edits. Generation and review receive explicit input numbering and reference roles. Geometry exceptions come only from the dedicated exceptions field. The original edit setup (.asun), masks, references, source image and every attempt image/settings/verdict remain stored with the job. Output image files are immutable per attempt.

For reviewed jobs, Sunburst/Flare/GPT Image 2 request a supported size with exactly the source aspect ratio, normally around a 1536-pixel long edge (1024 square). No crop/stretch/ratio rounding is used. Unsupported exact ratios stop before paid work; the user can re-export a standard-ratio Blender blockout or turn review off. Older models support only the existing square/3:2/2:3 shapes. Dimensions are shown before generation and in the result details. Non-reviewed job sizing is unchanged.

This is a visual consistency review, not a proof of exact 3D measurements, lens parameters or pixel identity. True world-space dimensional verification requires Blender scene metadata or a render workflow that preserves the actual scene.

RELIABILITY
Image and review calls have exclusive on-disk submission claims. Unknown network outcomes, malformed/contradictory reviews, refusal, unavailable settings, server restart and timeouts never trigger automatic paid re-submission. Only a valid rejection authorizes a new corrective attempt. Source/settings integrity is checked before dispatch. Queue remains running through review, leaving other workflow tabs editable. Polling does not repeatedly send large pending-candidate image payloads.
