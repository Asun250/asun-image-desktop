# ASUN desktop project library

[Download the full project collection](https://github.com/Asun250/asun-image-desktop/releases/download/project-library-2026-11-06/Asun-Image-Desktop-Project-Library-2026-11-06.zip) · [Release and checksums](https://github.com/Asun250/asun-image-desktop/releases/tag/project-library-2026-11-06)

This snapshot publishes the owner's stored desktop material: **44 jobs, 33 editable projects, 201 input/reference images, 37 generated outputs, and 40 recorded generation prompts**. Four older jobs have no saved prompt; no prompt was invented for them.

The archive contains full-resolution original images, native editable .asun projects where recorded, sanitized request/result metadata, prompt.txt files, and a SHA-256 file manifest. Original image and project bytes are preserved. Multiple .asun projects also embed their original references and annotations. No API keys, account credentials, queue-control markers or runtime process metadata are included.

## Open and use

1. Download and extract the ZIP.
2. Open a .project.asun file in ASUN Image to resume its editable source setup.
3. Import a job's final PNG to edit a generated result, or inspect its input images and record.json.
4. Read the saved prompt.txt or the links below for the exact recorded generation prompt.

Do not copy these snapshot folders into the app's live job queue. This is a portable project/media collection, not a running queue backup. Unsaved browser-only drafts and separate phone/plugin projects are outside this desktop snapshot. Older jobs can lack source-project or prompt records.
